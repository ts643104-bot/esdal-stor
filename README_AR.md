# Esdal Store (MVP) — متجر الإسدالات

متجر إلكتروني خفيف وسريع (React + Vite) لتصفح المنتجات وإضافتها للسلة ثم إرسال الطلب **بضغطة واحدة** إلى واتساب المتجر، مزود بلوحة تحكم للمدير تدعم الإحصائيات وإدارة المنتجات بشكل متكامل.

**رقم واتساب المستلم للطلبات:** `01122310891`  
**رقم محفظة فودافون كاش:** `01140971703`

---

## 1) كيف يعمل المتجر؟ (مواصفات الـ MVP)
- لا يحتاج لتسجيل دخول أو إنشاء حسابات للعميل.
- يدعم الدفع عند الاستلام (COD) و الدفع الإلكتروني (فودافون كاش / إنستاباي).
- الطلب يُرسل كرسالة واتساب جاهزة فيها: أسماء المنتجات + الكميات + الإجمالي + طريقة الدفع.
- يحتوي على **لوحة تحكم للمدير (Admin Panel)** محمية برقم سري لإضافة منتجات، متابعة الطلبات، وحساب أرباح المتجر بعد خصم المصروفات.

---

## 2) ربط الموقع بقاعدة بيانات (Database) عالمية باستخدام Supabase
لتتمكن من رفع المنتجات والأسعار بحيث تظهر لجميع الزوار على الإنترنت (وليس فقط على جهازك الشخصي)، تم تجهيز الموقع للارتباط بخدمة **Supabase** المجانية.

### خطوات التفعيل (سهلة جداً):
1. قم بإنشاء حساب مجاني على [Supabase](https://supabase.com).
2. قم بإنشاء مشروع (Project) جديد.
3. من القائمة الجانبية في مشروعك، اذهب إلى قسم **SQL Editor**.
4. انسخ جميع الأكواد الموجودة في ملف `supabase-schema.sql` والصقها هناك، ثم اضغط على زر **RUN**. (هذه الخطوة ستقوم بإنشاء جداول المنتجات والطلبات والمصروفات لك تلقائياً).
5. من القائمة الجانبية أيضاً، اذهب إلى إعدادات المشروع (Settings) ثم **API**.
6. قم بنسخ كل من الـ **Project URL** و الـ **anon public key**.
7. افتح ملف `.env` (يمكنك إنشاء واحد إن لم يكن موجوداً، أو استخدام `.env.example`) وضع البيانات كالتالي:

```bash
VITE_SUPABASE_URL="ضع_رابط_المشروع_هنا"
VITE_SUPABASE_ANON_KEY="ضع_مفتاح_anon_هنا"
```

> **ملاحظة هامة:** إذا لم تقم بتفعيل Supabase، سيعمل الموقع تلقائياً على نظام (Local Storage)، وهذا يعني أن التعديلات التي تجريها من لوحة التحكم ستظهر لك أنت فقط، ولن يراها العملاء. لذلك يرجى تفعيل Supabase.

## 3) التشغيل محلياً
```bash
pnpm install
pnpm dev
```

---

## 4) النشر (Vercel / Netlify)
- هذا الموقع هو مشروع React + Vite عادي.
- عند نشر الموقع (Deploy)، تأكد من إضافة المتغيرات (`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`) في إعدادات المنصة (Environment Variables) لكي تعمل قاعدة البيانات.

## 5) حماية الإدارة والأمان
- للوصول للوحة التحكم: انزل لأسفل الصفحة الرئيسية واضغط على "لوحة تحكم الإدارة".
- **كلمة المرور الافتراضية:** `esdal2026`
- **التنبيه الأمني للدفع الأونلاين:** الموقع يُحذر المدير بشدة من شحن أي طلب مدفوع إلكترونياً قبل تأكيد وصول الأموال إلى الحساب البنكي أو المحفظة شخصياً (مرفق إشعار باللون الأصفر داخل لوحة التحكم لغلق ثغرات الإيصالات المزيفة).
